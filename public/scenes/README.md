# Imagens das cenas

O app já funciona sem imagens externas usando ilustrações simples em CSS/emoji.

Para usar artes próprias, coloque os arquivos nesta pasta e adicione `image` à cena em `src/data/floresta-encantada.ts`:

```ts
image: "/scenes/floresta-vagalumes.webp",
```

Sugestão: imagens 16:9 ou 4:3, com composição simples e sem muito texto visual.
